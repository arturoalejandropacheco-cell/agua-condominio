Respaldo de datos

Los datos se guardan en este navegador. Si borras los datos de navegación o cambias de teléfono, se pierden. Descarga un respaldo cada cierto tiempo.

Conexión Google Sheets opcional

No hace falta para usar la app. Solo sirve si además quieres una copia de los datos en una planilla. Requiere una Hoja de Google nueva y vacía (no un archivo .xlsx).

Debe terminar en /exec. Sale de Apps Script → Implementar → Gestionar implementaciones. No es la URL de la planilla.

Sin conexión configurada: los datos se guardan solo en este navegador (localStorage).

Con conexión: los datos se sincronizan automáticamente con tu Google Sheet.
